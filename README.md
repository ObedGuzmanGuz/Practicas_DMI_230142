## 📚 Descripción

Repositorio correspondiente a las prácticas realizadas en la asignatura de **Desarrollo Móvil Integral**, perteneciente a la carrera de **Ingeniería en Desarrollo y Gestión de Software**.

En este repositorio se documentan las actividades, prácticas y aplicaciones desarrolladas durante el curso, utilizando principalmente el framework **Flutter** y el lenguaje de programación **Dart**.
