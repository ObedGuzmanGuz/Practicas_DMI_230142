# Laboratorio Digital

Aplicación de ejemplo desarrollada con Flutter para explorar componentes de interfaz, botones, tarjetas, controles, barras de progreso animadas y personalización de colores.

## Cambios de esta versión

- Interfaz oscura con fondo negro y nuevos colores de acento.
- Textos y mensajes de la interfaz en español.
- Ilustración de portada cargada desde la URL indicada.
- Animación continua de los indicadores de progreso.
- Se conservan las pantallas y las funciones de navegación, controles y carga de la galería.

## Ejecutar

1. Instala Flutter y las dependencias del proyecto.
2. Ejecuta `flutter pub get`.
3. Ejecuta `flutter run`.
