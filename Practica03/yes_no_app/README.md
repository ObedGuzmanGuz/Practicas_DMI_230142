## Arquitectura interactiva · práctica 03

Abre [el diagrama de Yes No App](arquitectura/arquitectura_yes_no_app.html) con
doble clic en un navegador. Incluye el flujo real del chat, seis plataformas,
paneles de detalles, fragmentos de código y enlaces a GitHub. Es un HTML autónomo;
no necesita Flutter ni ejecuta el chat.

[Visualizar en GitHub Pages — URL prevista, publicación no verificada](https://obedguzmanguz.github.io/Practicas_DMI_230142/Practica03/yes_no_app/arquitectura/arquitectura_yes_no_app.html).

Para publicarlo, Pages debe usar la rama que contenga los archivos y `/(root)`.
Si se elige `main`, primero deben fusionarse allí. La referencia de los enlaces
es independiente: tras la fusión, cambia `codeRef` a `main` en
`arquitectura/configuracion.json` y regenera el HTML. La carpeta `appPath` sigue
siendo `Practica03/yes_no_app`.

Consulta [las instrucciones y el alcance de la revisión](arquitectura/README.md).
